   - Добавлены взносы ПФР/ФСС: травматизм, единый тариф, ЕФС-1, РСВ.

6. Выбор типа задачи — сворачиваемая группа «Отчётность»
   - 17 типов по всем видам сроков: декларации (НДС, прибыль),
     6-НДФЛ, уплаты (НДФЛ, НДС, прибыль, УСН, транспорт, имущество,
     взносы), уведомления (НДФЛ, УСН, транспорт), РСВ, ЕФС-1, ПСФ,

     формы создания и календаря).

7. Страница «Клиенты» — кнопка «Создать записи по таблице отчётности»
   - Создаёт карточки по всем клиентам по всем срокам, подходящим
     под их систему налогообложения.
   - «Что нужно сделать» = название срока; ответственный — Анастасия;
     план — 30 минут; статус — Новая.
   - Повторное нажатие карточки не дублирует (проверка по сроку).

8. Сроки НДФЛ — только по датам выплат клиента
   - «НДФЛ: уплата удержанного за 23–30 сентября» — если день аванса
     или зарплаты попадает в период с 23 по 30.
   - «НДФЛ: уведомление за октябрь» — если день аванса или зарплаты
     с 01 по 22.

9. Карточки сроков отчётности и налогов — светло-жёлтые
   - На доске задач и в календаре планов; заливка светлая (#fffef7).

10. Страницы «Клиенты» и «Отчётность» доступны Анастасии
    - Вместе со всем содержимым: просмотр, создание и редактирование
      клиентов, таблица сроков, кнопка «Создать записи по таблице
      отчётности».

11. Дата выполнения в таблице «Отчётность»
    - При переводе карточки в «Выполнено» в ячейке таблицы вместо «✓»
      появляется дата выполнения (дд.мм); при возврате из «Выполнено»
      дата сбрасывается.

12. Таблица «Отчётность»: закрепление
    - Строка с названиями колонок закреплена сверху при прокрутке вниз.
    - Названия видов налогообложения (группы) закреплены по левому
      краю при прокрутке вправо.

13. Уведомления по НДФЛ на АУСН не подаются
    - Клиентам на АУСН эти сроки не показываются и карточки
      не создаются.

14. Уведомления по НДФЛ у ИП без сотрудников не подаются
    - Если форма — ИП и сотрудников 0 — сроки-уведомления НДФЛ
      для этого клиента не показываются и карточки не создаются.

15. Страховые взносы (уплата) при количестве сотрудников = 0
    - Если у клиента сотрудников 0 — сроки «Страховые взносы …
      уплата» не показываются и карточки не создаются.

16. Страховые взносы по единому тарифу (уплата) на АУСН

      не создаётся.

      только клиенту «Солнечная Архитектура»; остальным — не
      показываются и карточки не создаются.

18. ИП без сотрудников: часть отчётности не подаётся
    - Для ИП с количеством сотрудников 0 не показываются и не
      создаются сроки: 6-НДФЛ, ПСФ, ЕФС-1, РСВ.
